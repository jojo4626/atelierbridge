# Sécurité

Si vous découvrez une vulnérabilité pouvant compromettre des documents locaux,
le téléchargement de modules ou le mécanisme de signature, évitez de publier des
secrets ou un exploit sur une issue publique. Le mainteneur peut activer
**Private vulnerability reporting** dans les paramètres du dépôt GitHub.

Les modules ne sont pas maintenus par AtelierBridge. Les vulnérabilités propres
à un module doivent également être signalées à ses auteurs.

Les correctifs de sécurité sont publiés exclusivement via des APK signées et
répertoriées dans les Releases officielles du dépôt. Vérifiez leur empreinte
SHA-256 avec le fichier accompagnant chaque APK.
