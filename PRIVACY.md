# Confidentialité

AtelierBridge n'intègre ni compte utilisateur, ni publicité, ni suivi analytique.
Les projets et modules téléchargés sont stockés localement sur l'appareil.

Une connexion à l'API et aux fichiers GitHub est établie lorsque l'utilisateur
cherche, installe ou met à jour un module. GitHub peut traiter les métadonnées
usuelles des connexions selon sa propre politique de confidentialité.

Pour ouvrir des documents, Android demande une autorisation explicite via le
sélecteur système. L'application n'a pas accès à l'ensemble de la galerie.
Pour enregistrer un export, Android affiche un sélecteur de destination.
L'historique des exports est local à l'application. Aucun fichier sélectionné
n'est transmis à notre propre serveur.

Les modules sont des logiciels tiers qui s'exécutent dans une WebView locale.
Le lanceur filtre les requêtes HTTP(S) de la WebView vers des ressources
externes, mais il ne garantit pas une isolation réseau totale de tous les
modules ou de toutes les API du navigateur. Il est recommandé de n'installer
que des modules provenant de sources vérifiées.

Contact et rapports de sécurité : utilisez les issues privées ou les canaux
de communication définis sur le dépôt de publication.
